# Ease Scrubber Slider Timeline

An interactive timeline component built with native HTML5, CSS3 transitions, and vanilla JavaScript using custom canvas/SVG plotting algorithms to map complex time animations and velocity mappings.

## 🚀 Key Features
- **Dynamic Scrubbing:** Slide or click anywhere along the track boundaries to jump to exact structural raw timestamps.
- **Velocity Easing Presets:** Live vector calculations for Linear, Quad Ease-In, Quad Ease-Out, and Cubic Ease-In-Out behaviors.
- **Dual Indicators:** Track both your absolute physical playhead handle location and the relative destination value simultaneously.
- **Fully Responsive & Custom Grid:** Fluid SVG layout graphs responsive down to small mobile touch viewports.

## 📁 Technical Framework
- **Structural Model:** Vanilla DOM API and high-performance `window.requestAnimationFrame` loops.
- **Icons Vectoring:** Lucide Elements CDN engine.
- **Styling Paradigm:** Isolated scope CSS layouts utilizing modern dynamic CSS variables.
